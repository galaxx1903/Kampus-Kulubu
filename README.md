# Kampüs Oyun Topluluğu

Kampüs Oyun Topluluğu, öğrencileri oyun oynamak, oyun kültürünü paylaşmak ve oyun fikirleri üretmek için bir araya getiren üç sayfalık statik bir web projesidir. Etkinlik sayfasında başlığa göre canlı arama bulunur.

## Sayfalar
- `index.html`: Topluluğu tanıtır ve oyun, üretim ve buluşma alanlarını gösterir.
- `etkinlikler.html`: Beş etkinlik kartını, arama alanını ve sonuç sayısını içerir.
- `hakkimizda.html`: Topluluğun amacı ve yaklaşımı hakkında bilgi verir.

## Çalıştırma
1. Proje kök klasöründe bir terminal açın.
2. Şu komutu çalıştırın:

```bash
python3 -m http.server 8000
```

3. Tarayıcıda `http://localhost:8000` adresini açın. Sunucuyu durdurmak için terminalde `Ctrl+C` tuşlarına basın.

Ek paket veya framework kurulumu gerekmez.
